Identité et arbitrage

LINEAR → LINEAR ou ARBITRAGE ; TIERED → RCD ou COMPLEMENT ; FIXED → FEE ; EXTERNAL → EXTERNAL ou INSURER.
Dans un même groupe, seule la priorité la plus haute s'applique ; les groupes différents se cumulent. Le nom du groupe est libre, sauf BASE, réservé aux règles de base : un événement sans règle de base passe en attente (ON_HOLD, P8). Convention proposée, non imposée par le moteur : barème général 10, opération commerciale 20, accord dérogatoire 30. Deux versions du même groupe, de même priorité, dont les périmètres et les dates se recouvrent : l'approbation de la seconde est refusée.

Périmètre

Un critère vide signifie « tous » ; un critère à plusieurs valeurs signifie « l'une d'elles ». Le périmètre est une conjonction : pour « produit A ou distributeur B », créer deux règles. Il n'exprime pas d'exclusion : lister les produits inclus.

Couples apport + suivi autorisés

Une garantie dont le couple n'est pas dans la grille passe en attente (ON_HOLD) avec l'anomalie « taux hors grille ». L'apport est dû pendant les 365 premiers jours à partir de la date d'effet de la garantie ; une prime à cheval sur la limite est répartie au prorata des jours.
